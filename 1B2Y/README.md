# 1B2Y Docking Protocol Validation

## 1. Overview

This repository contains the input files, docking configuration, output poses, and validation results for a molecular docking redocking test using the protein structure **PDB ID: 1B2Y** and AutoDock Vina.

The purpose is to document the docking setup, enable rerunning of the calculation, and provide a reference for evaluating the docking protocol.

## 2. Software requirements

- **AutoDock Vina:** 1.2.7
- **Operating system:** Windows 10/11 (the supplied batch script is for Windows)
- **Reference structure:** PDB ID 1B2Y, obtained from the RCSB Protein Data Bank

AutoDock Vina must be installed or its executable must be accessible to the batch script.

## 5. How to rerun docking

1. Download or clone this repository while preserving the directory structure.
2. Install AutoDock Vina 1.2.7, or obtain the executable from the official AutoDock Vina distribution.
3. Open `run_docking.bat` and follow its instructions if the executable is not automatically detected.
4. Ensure the following files are present in the same directory:
   - `config.txt`
   - `receptor_vina.pdbqt`
   - `ligand_OB_prepared.pdbqt`
5. Run `run_docking.bat`.
6. Check `docked_test.pdbqt` for the resulting poses and `docking_log.txt` for the run output.

The script overwrites the existing `docked_test.pdbqt` and `docking_log.txt` files. Back up the original outputs before rerunning if you want to preserve the recorded run.

## 7. RMSD validation

The recorded external RMSD result from PACDOCK ProRMSD was **0.653 Å**.

The recorded reference and docked pose each contained 54 heavy atoms. Equal heavy-atom counts alone do not establish correct atom correspondence. The RMSD value should therefore be interpreted in the context of the reference and docked structures, atom mapping, any symmetry handling, and whether coordinate superposition was applied.

For independent reproduction, retain the exact reference coordinates, the compared docked pose, and the RMSD calculation settings or method. The PACDOCK ProRMSD value is recorded separately from Vina's within-run pose RMSDs.

## 8. Scope and limitations

This repository documents the 1B2Y redocking example. It does not, by itself, establish that the same docking box, receptor preparation, or protocol is appropriate for every other protein target.

For subsequent docking studies, confirm receptor preparation, ligand preparation, protonation and charge assignment, search-space selection, and validation suitability for the target of interest.
